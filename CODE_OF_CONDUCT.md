## Code de Conduite

Nous nous engageons à fournir une expérience de collaboration ouverte et respectueuse pour tous.

### Engagement

- Respect mutuel, pas de harcèlement
- Communication constructive
- Inclusion et collaboration bienveillante

### Signalement

Pour signaler un comportement inapproprié, ouvrez une Issue privée ou contactez les mainteneurs.

### Applicabilité

Ce code s’applique à tous les espaces du projet (issues, PR, discussions, chat).
